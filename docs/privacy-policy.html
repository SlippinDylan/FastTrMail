FastTrMail Privacy Policy

Effective date: 2026-06-03

FastTrMail is a Chrome extension that adds inline translation to Fastmail web message views. This policy explains what data the extension handles and how that data is used.

Summary

  • FastTrMail does not collect personal data on developer-controlled servers.
  • FastTrMail only sends email content to the translation service you choose.
  • API credentials for official providers are stored only for the current browser session.
  • FastTrMail does not sell data.
  • FastTrMail does not use data for advertising, profiling, or marketing.

What the extension accesses

When you use FastTrMail on Fastmail Web, the extension reads the visible email title and message body content needed to produce a translation in the page.

What data is sent to third parties

If you request a translation, FastTrMail sends the text you choose to translate to the translation provider currently selected in the extension settings. Depending on your configuration, that provider may be Google or Microsoft.

If you use Google Cloud API or Microsoft Translator API, the credentials you provide are also sent to the corresponding provider for authentication as part of the core translation request.

The developer of FastTrMail does not receive a copy of the email content being translated.

What data is stored locally

FastTrMail stores the following settings in Chrome storage on your device:

  • Selected translation provider in chrome.storage.local
  • Selected target language in chrome.storage.local
  • Selected uiLanguage in chrome.storage.local
  • Google API key in chrome.storage.session, if you provide one
  • Microsoft API key and region in chrome.storage.session, if you provide them

This information is used only to make the extension work. It is not transmitted to the developer.

Data sharing and sale

FastTrMail does not sell user data. It does not share user data with data brokers, advertisers, or analytics platforms. Data is only sent to the translation provider you explicitly use for the core translation function.

Security

FastTrMail uses HTTPS requests for supported translation providers. Official-provider API credentials are stored only for the current browser session and are not persisted across browser restarts.

Your choices

You can remove stored settings at any time by clearing the extension's storage or by uninstalling the extension. You can also stop sending email content to a provider by not using the translation feature, and you can clear session-stored API credentials by closing the current browser session.

Contact

For questions about this policy, please open an issue on the project repository: github.com/SlippinDylan/FastTrMail/issues
